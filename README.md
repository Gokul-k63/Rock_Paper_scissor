# Stone Paper Scissors Game 🪨📄✂️

A simple Stone Paper Scissors game built using Python.

## Features

- If the user enters an invalid input, they get 3 chances. After that, the game exits.
- If a match ends in a draw, an extra round is added.
- Used a `while` loop instead of a `for` loop because the number of rounds can increase whenever a draw happens.
- Game details are stored in a JSON file for future reference.
- if the file is not found it create automatically to your folder.

## Stored Details
- User Name
- Winner
- Score
- Playing Time

## Concepts Used
- Python Loops (`while`)
- Conditional Statements
- Random Module
- JSON File Handling
- Exception Handling
